# Hilit Code Review

리뷰 작업을 시작하기 전에 [`docs/workflows/pr-review.md`](../../../docs/workflows/pr-review.md)를 처음부터 끝까지 읽는다. 이 문서를 이 스킬의 권위 있는 본문으로 취급하고 필수 문서, 점검표, 출력 형식, 심각도 기준과 중단 조건을 모두 따른다.

상대 경로는 저장소 루트를 기준으로 해석한다. 워크플로에 명시된 대로 우선순위가 더 높은 저장소 문서와 현재 사용자 지시를 우선한다.
