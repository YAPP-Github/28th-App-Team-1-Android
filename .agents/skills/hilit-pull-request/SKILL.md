# Hilit Pull Request

Pull Request 작업을 시작하기 전에 [`docs/workflows/pull-request.md`](../../../docs/workflows/pull-request.md)를 처음부터 끝까지 읽는다. 이 문서를 이 스킬의 권위 있는 본문으로 취급하고 사전 조건, 리뷰·검증 반복 절차, 커밋 규칙, PR 템플릿 요구사항, 확인 단계, 대체 절차와 중단 조건을 모두 따른다.

이 워크플로는 [`docs/workflows/pr-review.md`](../../../docs/workflows/pr-review.md)를 포함한다. Pull Request 워크플로에서 자체 리뷰 점검표를 요구할 때 이 문서도 처음부터 끝까지 읽는다.

상대 경로는 저장소 루트를 기준으로 해석한다. 워크플로에 명시된 대로 우선순위가 더 높은 저장소 문서와 현재 사용자 지시를 우선한다.
